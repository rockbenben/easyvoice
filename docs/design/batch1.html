4 · 字幕配音

B1后端字幕表头首次渲染泄漏 __i18n__{"key":"sub.col_speaker"} 原始 JSON

根因：gr.Dataframe(headers=[I18N(...)]) 的 i18n 代理对象不被 Dataframe 表头解析（其它组件都支持，唯独这里塌了）；load 后的 relabel 又晚于首帧。改后：headers 初始用构建期简体纯字符串，本地化仍走 _relabel（已存在），删掉 headers 里的 I18N() 调用。

同轮消费者：ui.py sub_table 构造一处；_relabel_updates 已覆盖 headers，不动；测试无逐字钉。

B2后端状态列裸显示 pending / dirty / ok / error

开发者内部值直达用户。改后：_sub_table 按请求语言映射为「待生成 / 已改动 / 完成 / 失败」（新增 st.* 三语键），所有回传表格的 handler 统一走映射。

同轮消费者：_sub_table 及全部调用点（parse / select / edit / reroll / gen_all / export 后刷新）；语言来源用已有 _vloc State；test_dubbing_project 若断言内部值仍用原枚举，仅 UI 层映射。
